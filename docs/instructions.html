CLASSIC MODE

Game Start:

The player selects a game mode (Easy, Normal, Hard, Ultra-Hard).

The game area and target will appear, and the timer will start.

Game Modes Description:

  • Easy: The target appears and stays visible for 2 seconds (2000 ms).
  • Normal: The target appears and stays visible for 1 second (1000 ms).
  • Hard: The target appears for 1 second (1000 ms), with a 50% chance of a fake target appearing, which disappears after 700 ms (clicking it will reset the score).
  • Ultra-Hard: The target appears and disappears in 0.5 seconds (500 ms).

Clicking on the Target:

The player clicks on the moving target.

If they hit it, the score increases, and a sound is played.

If they miss, the score remains the same (or decreases for a fake target).

Time Limit:

The game lasts for 30 seconds.

After the time is up, the game ends and a results window is displayed.
